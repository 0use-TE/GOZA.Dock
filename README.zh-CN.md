# GOZA.Dock

Avalonia 停靠布局：`Grid` + `DockRegion` + `DockSplitter`。

```bash
dotnet run --project samples/GOZA.Dock.Minimal.Desktop
dotnet add package GOZA.Dock --version 1.0.1
```

依赖 **Avalonia 12.0.0+**。发布说明见文档 [Release notes](docs/v1.0/release-notes.md)。

文档：https://0use.net/GOZA.Dock/（顶栏 **Version** / **Lang** 切换）。浏览器 Demo（WASM）：https://0use.net/GOZA.Dock/demo/

本地文档：`docfx docfx.json && docfx serve _site --port 8080`
