# GOZA.Dock 3.0.8

AOT-first fixed dock regions with lookless Avalonia controls, VS Code workbench color themes (`DockShell.ColorTheme`), optional view reuse, and explicit tab drag/drop.

See the [Quick Start](getting-started.md) for installation and a complete workspace walkthrough. Theming: [Theming](theming.md) · [DOCK-THEMING.zh-CN.md](https://github.com/0use-TE/GOZA.Dock/blob/master/DOCK-THEMING.zh-CN.md).
