# GOZA.Dock

Cross-platform Avalonia docking — draggable tabs, closable documents, optional view parking lot.

```bash
dotnet run --project samples/GOZA.Dock.Minimal.Desktop
dotnet add package GOZA.Dock --version 1.0.2
```

Use **Version** and **Lang** in the top navbar, then open [Quick Start](docs/v1.0/getting-started.md).
