# VS Code theme-defaults (local)

Copied from [microsoft/vscode](https://github.com/microsoft/vscode) `extensions/theme-defaults/themes`
(MIT). Used by GOZA.Dock.Demo via `DemoVsCodeThemePack` + `VsCodeThemeJson.Load` (resolves `include` chains).

| File | Typical name |
|------|----------------|
| `dark_modern.json` / `light_modern.json` | Dark / Light Modern |
| `dark_plus.json` / `light_plus.json` | Dark+ / Light+ |
| `dark_vs.json` / `light_vs.json` | Dark / Light (Visual Studio) |
| `2026-dark.json` / `2026-light.json` | 2026 Dark / Light |
| `hc_black.json` / `hc_light.json` | High Contrast |

`manifest.json` lists menu order and `uiTheme` when the leaf JSON omits `type`.
